# Germany by State - Economy and Society

Compares Germany's 16 states (Bundesländer) on 15 economic and social indicators in one reference year (2025), with one choropleth map and one ranked chart per indicator. Disposable income is only published up to 2024, so it has its own tab.

## Data Sources

| Source | Access | Indicators | Latest year (Sept 2026) | Licence |
|---|---|---|---|---|
| [Destatis GENESIS-Online](https://www-genesis.destatis.de) | REST API 2020 (`/genesisWS/rest/2020/data/tablefile`, flat CSV), free account token | population, area, age, citizenship, fertility, migration, registered unemployment, building land prices, hourly earnings, gender pay gap, life expectancy | 2025 (life table 2023/25, area 2023) | dl-de/by-2-0 |
| [Arbeitskreis VGR der Länder](https://www.statistikportal.de/de/vgrdl) | Excel releases | GDP per inhabitant, disposable income per inhabitant | GDP 2025, income 2024 | dl-de/by-2-0 |
| [Eurostat](https://ec.europa.eu/eurostat/web/regions/database) | Dissemination API, JSON-stat, no key | employment rate 20-64 (`lfst_r_lfe2emprt`), tertiary education (`edat_lfse_04`), at-risk-of-poverty rate (`ilc_li41`), NUTS 1 | 2025 | CC BY 4.0 |
| [Eurostat GISCO](https://ec.europa.eu/eurostat/web/gisco/geodata/statistical-units/territorial-units-statistics) | GeoJSON download | NUTS 2024 level 1 boundaries, 1:10 million | NUTS 2024 | © EuroGeographics |

Sources checked and not used:
- **2026 values:** only monthly unemployment and a preliminary H1 GDP exist, so no indicator has a complete 2026 year.
- **INKAR (BBSR):** ends in 2023.
- **Kreis level (400 districts):** complete only for 2024, and has no official poverty or life-expectancy series.
- **Low-wage job share:** Destatis suppresses the 2025 value for Mecklenburg-Vorpommern.

The GENESIS API needs a free account. Register at https://www-genesis.destatis.de/datenbank/online, copy the API token from the profile page, and add it to the repo-root `.bruin.yml` as a generic secret named `destatos-genesis-germany-key`. Guest access no longer returns data.

## Assets

**Raw** (`assets/raw/`, Python, append; each run fetches the last four years up to `BRUIN_END_DATE`)
- `raw.de_genesis_tables`: 15 GENESIS tables in long format (one row per published cell, special signs kept in `value_raw`). Tables too large for one request are fetched year by year.
- `raw.de_vgrdl_accounts`: GDP and disposable income per inhabitant from the VGRdL Excel releases.
- `raw.de_eurostat_nuts1`: three Eurostat datasets for DE1-DEG and DE.
- `raw.de_state_boundaries`: 16 GISCO NUTS 1 polygons as GeoJSON MultiPolygon (create+replace).

**Staging** (`assets/staging/`)
- `staging.de_states`: AGS code, NUTS 1 code, names, abbreviation, East/West group, map label anchor.
- `staging.de_state_indicators`: long table of all indicators, 16 states plus Germany, all years. It deduplicates the raw data and derives density, age and citizenship shares, and net migration per 1,000.
- `staging.de_indicator_catalog`: labels, units, formats, fixed reference year, source, licence, definition, and mapped/excluded flag per indicator.

**Report** (`assets/report/`)
- `report.de_state_indicator_snapshot`: one row per mapped indicator and state in its reference year, with Germany value, difference, rank, and labels. A custom check fails the run unless every indicator has 16 states and one year.
- `report.de_indicator_quality`: reference period, latest year available, and state coverage per indicator.
- `report.de_indicator_correlations`: Pearson r between all 2025 indicators across the 16 states.

## Dashboard

`dashboard-dac/dashboards/germany-regions.yml` is generated by `dashboard-dac/scripts/build_dashboard.py`. Edit the script (indicator config, insight text, specs), not the YAML. The script reads state geometry from `raw.de_state_boundaries` and embeds it once as a named Vega-Lite dataset. Values come from SQL at view time.

Tabs:
- **Overview:** KPIs, East-West table, correlation matrix.
- **Economy:** 6 maps.
- **Society:** 9 maps.
- **Income (2024):** 1 map.
- **Data quality & methodology.**

## Run Commands

```bash
bruin validate germany-regions/

# Ingestion (each raw asset fetches the four years up to the end date)
bruin run --end-date 2025-12-31 germany-regions/assets/raw/de_genesis_tables.py
bruin run --end-date 2025-12-31 germany-regions/assets/raw/de_vgrdl_accounts.py
bruin run --end-date 2025-12-31 germany-regions/assets/raw/de_eurostat_nuts1.py
bruin run germany-regions/assets/raw/de_state_boundaries.py

# Staging + report
bruin run --downstream germany-regions/assets/staging/de_states.sql

# Dashboard
python3 germany-regions/dashboard-dac/scripts/build_dashboard.py
dac validate --dir germany-regions/dashboard-dac
dac check --dir germany-regions/dashboard-dac
dac serve --dir germany-regions/dashboard-dac --port 8321 --template germany-regions/dashboard-dac/themes/ibm-cb-dark.yml
```

Dashboard URL: <http://localhost:8321> (use another port if 8321 is taken).

## Known Limitations

- **Reference years:** 2025 throughout, except disposable income (2024) and life expectancy (2023/25 three-year life table ending 2025). Population density uses the latest official area (31 Dec 2023).
- **Revisions:** 2025 GDP and the 2023/25 life table are first releases and may be revised.
- **Unit size:** states are large, unequal units. City-states contain urban cores without their suburbs, which inflates GDP per inhabitant through in-commuting.
- **Survey error:** survey-based indicators (employment, tertiary education, poverty risk) have sampling error, largest for Bremen and Saarland.
- **Poverty line:** the at-risk-of-poverty rate uses the national median, not regional price levels.
- **Rounding:** Destatis publishes the gender pay gap rounded to whole percentage points.
- **Correlations:** based on n = 16 states, so they describe states, not individuals.
- **Source URLs:** VGRdL release URLs are versioned, so update `WORKBOOKS` in `de_vgrdl_accounts.py` when a new release appears.
